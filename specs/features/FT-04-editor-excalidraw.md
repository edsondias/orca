# FT-04: Editor Excalidraw

Épico: [EP-02](../epics/EP-02-editor-excalidraw.md).
Design: [specs/orca-excalidraw-design.md](../orca-excalidraw-design.md).

## Descrição

O Orca reconhece `*.excalidraw` e `*.excalidraw.json`, abre o arquivo como desenho editável e grava o JSON padrão do Excalidraw.
O tema segue o Orca, a biblioteca de formas é global e o explorador oferece a criação de um desenho novo.
